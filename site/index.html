Búsqueda web para agentes locales en 44 MB de RAM.

Servidor local y herramienta MCP drop-in que emula la API de Tavily usando DuckDuckGo. Sin Docker, sin API keys y sin bases de datos.

Comenzar en 30 segundos Ver repositorio
# Instalar sin clonar e iniciar de inmediato
$ pipx install git+https://github.com/yeib/yeivily.git
$ yeivily
# Yeivily 1.0.0 listening on http://127.0.0.1:8000
# Agregar a ~/.config/goose/config.yaml
extensions:
  yeivily_search:
    type: stdio
    cmd: yeivily-mcp
    enabled: true
# Funciona con el cliente oficial tavily-python
from tavily import TavilyClient
client = TavilyClient(api_key="mock", api_base_url="http://127.0.0.1:8000")
res = client.search("Ollama latest release", max_results=3)
print(res["results"])
$ curl -s localhost:8000/search -H 'Content-Type: application/json' \

La prueba de los 44 MB de RAM

La mayoría de las soluciones de búsqueda local para LLMs te obligan a levantar contenedores Docker con SearXNG, Redis y Python Uvicorn que devoran hasta 1 GB de memoria en tu PC. Yeivily corre en librería estándar pura + ddgs, manteniendo tu máquina fría y libre para el modelo.

Yeivily (Daemon HTTP bajo carga real) ~44 MB
FastAPI / Uvicorn DDGS proxy ~210 MB
SearXNG + Redis + Docker stack ~850 MB
🐳

Zero Docker

Sin archivos docker-compose, sin puertos bloqueados por hipervisores y sin descargar 5 GB de imágenes a tu SSD. Es un único script Python que levanta en 15 milisegundos.

  • Inicio en < 20 ms
  • Cero demonios extraños
  • Portátil en Windows, Linux y Mac
🤖

Dual Engine: HTTP + MCP Stdio

Habla tanto la API REST de Tavily (/search, /extract) como el protocolo nativo Model Context Protocol (MCP) sobre stdio. Si el daemon está apagado, el worker MCP corre el motor en proceso de forma transparente.

🛡️

Escudo contra Rate-Limits y Bloqueos de DuckDuckGo

Los LLMs suelen hacer consultas idénticas o repetitivas que queman IPs rápidamente. Yeivily implementa tres capas de blindaje:

  • Caché LRU + TTL de 10 minutos: Las búsquedas repetidas devuelven resultado instantáneo en 0 ms.
  • Single-Flight Deduplication: Si tres agentes piden lo mismo al mismo segundo, se hace una sola petición aguas arriba.
  • 429 Honesto con Retry-After: Si DuckDuckGo bloquea temporalmente, Yeivily responde con código 429 y cabecera de enfriamiento en vez de mentir diciendo que hubo "0 resultados".
🔒

Seguridad contra SSRF y DNS Rebinding

Diseñado para convivir seguro con navegadores y agentes locales. Rechaza peticiones cross-origin no autorizadas, protege puertos privados y bloquea intentos de extracción hacia 127.0.0.1 o redes internas corporativas.
